# 📱 Real-Time Social Media Feed Application

A dynamic social media application with real-time feed updates, likes, and comment threads[cite: 1].

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Socket.io-client
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** MongoDB

## 🚀 Features
- Real-time post updates using WebSockets[cite: 1]
- Interactive likes and threaded comments[cite: 1]
- User registration and posting[cite: 1]
